# Noor-e-Quran

Quran Sharif app (PWA) — Roman English aur Arabic ayat, Urdu aur Roman Urdu tarjuma, ruku-wise marking, namaz ke auqat, masnoon duaein aur Tabligh section (muzakare ke 14 tafseeli bayan — chhe sifaat, gasht, maghrib ki baat, jamaat ke usool — deen ke faraiz, wuzu, sunnatein).

Live: https://vahab0597-dev.github.io/quran/

## Sources
- Quran text (Uthmani) & Roman transliteration: Tanzil.net (via `quran-json`)
- Urdu tarjuma: Fateh Muhammad Jalandhry (Tanzil, via fawazahmed0/quran-api)
- Roman Urdu tarjuma: Maulana Abul A'la Maududi (quranromanurdu.com, via fawazahmed0/quran-api; English glosses in brackets removed)
- Ruku/Para data: `quran-meta` (Indo-Pak, 556 ruku)
- Namaz times: `adhan` (Karachi method, Hanafi Asr by default)
