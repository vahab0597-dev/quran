# Noor-e-Quran

Quran Sharif app (PWA) — Roman English aur Arabic ayat, Urdu/English tarjuma, ruku-wise marking, namaz ke auqat, masnoon duaein aur Tabligh section (chhe sifaat, gasht, muzakare, deen ke faraiz, wuzu, sunnatein).

Live: https://vahab0597-dev.github.io/quran/

## Sources
- Quran text (Uthmani) & Roman transliteration: Tanzil.net (via `quran-json`)
- Urdu tarjuma: Fateh Muhammad Jalandhry (Tanzil, via fawazahmed0/quran-api)
- English: Saheeh International
- Ruku/Para data: `quran-meta` (Indo-Pak, 556 ruku)
- Namaz times: `adhan` (Karachi method, Hanafi Asr by default)
